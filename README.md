# 地铁跑酷 3D（Subway Surfers 3D）

纯前端实现的 3D 三轨道跑酷游戏，用 Three.js 手写，**零构建、零服务器**，双击 `index.html` 就能玩。

美术风格对着原版录屏逐帧还原：万圣节特兰西瓦尼亚村落、会行驶的火车、坡道跑上车顶、警察 + 警犬追捕。

## 直接下载玩

不想看代码就去 [Releases](https://github.com/jianshenghuang2922/subway-surfers/releases/latest) 下载：

- **`subway-surfers-3d-v1.0.0.html`** —— 单文件版，777 KB，双击即玩，不用解压
- **`subway-surfers-3d-v1.0.0.zip`** —— 多文件版，解压后双击 `index.html`

支持 Chrome / Edge / Firefox 等现代浏览器，桌面和手机都能跑。

## 玩法

- 三条轨道，速度随距离递增（26 → 56）
- 撞上障碍：**第一次**只是被追捕者逮住，他会跟在你身后纠缠 **10 秒**；这 10 秒内**再撞一次**才结束游戏
- 吃金币，结算进钱包，去商店解锁角色
- 坡道跑上火车顶，可以在车顶上横向换道

## 角色与商店

6 个角色，每个 15 组配色（帽子 / 帽顶 / 皮肤 / 头发 / 上衣 / 牛仔裤 / 鞋面 / 鞋条 / 鞋底 / 背包 / 手套……），选中后直接改 3D 模型材质，不重建模型。

存档写在 `localStorage`：钱包、已拥有角色、当前角色，关掉浏览器还在。

## 技术要点

- **Three.js r150 UMD 本地副本**，无 npm、无打包器、无服务器
- **对象池**：障碍、金币全部复用，不产生 GC 抖动
- **InstancedMesh**：枕木 90×3、接触阴影 90×3，一次 draw call 画完
- **扫掠 AABB 碰撞**：按速度外扩包围盒，高速下不漏判
- **地形高度函数** `groundHeightAt(x, z, y)`：地面 0 / 坡道斜面 / 车顶 4.76 统一求解，坡道是地形不是障碍
- **段结构生成器**：`corridor`（车流走廊）与 `open`（开阔段）交替，控制节奏不堆满
- 纯 CSS 画的 UI：图标、角色小头像全部 CSS 拼，无图片资源

## 开发调试参数

URL 上带参数可以直接跳到某个状态，方便截图和回归：

| 参数 | 作用 |
|---|---|
| `?auto=1` | 跳过菜单直接开跑 |
| `?nointro=1` | 跳过开场镜头 |
| `?ff=N` | 以 1/60 步长空跑 N 帧后冻结 |
| `?panel=chars\|shop` | 直接打开角色 / 商店面板 |
| `?rampdemo=1\|2\|3` | 摆 1/2/3 条并排坡道，验证上坡与车顶换道 |
| `?hit=N&hits=K&gap=F` | 连撞 K 次，间隔 F 帧，验证两段式抓捕 |
| `?gl=N` | 撞一次后空跑 N 秒，验证抓捕者 10 秒退场 |
| `?god=1` | 撞不死 |
| `?ui=buy` / `?ui=reset` | 模拟购买 / 清存档 |
